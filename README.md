# Steel Insights (SteelAgent Core)

An open-source high-fidelity data extraction and sandbox pipeline designed for structured market intelligence analysis.

## 🌟 Features
- **Data Edge Bounding**: Strict isolation and sanitation of raw data structures before LLM injection.
- **Adaptive Sampling Strategy**: Dynamic context window optimizations for high-density document feeds.
- **Structured Prompt Framework**: Decoupled prompt layers ensuring predictable JSON intelligence outputs.

## 🛠️ Quick Start
1. `npm install`
2. Configure `.env`
3. `npm start`
